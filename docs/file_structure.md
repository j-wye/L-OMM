# L-OMM Workspace Folder Guide

이 문서는 AI 에이전트와 사람이 빠르게 프로젝트 맥락을 파악할 수 있도록, 파일 단위가 아닌 폴더 단위 구조만 설명한다.

## 문서 운영 원칙
- 이 문서는 폴더와 하위 폴더의 역할만 다룬다.
- 개별 파일 설명은 포함하지 않는다.
- 새 파일이 추가되더라도, 폴더의 역할이 바뀌지 않으면 이 문서는 수정하지 않는다.
- 폴더의 목적이나 계층이 바뀔 때만 업데이트한다.

## 최상위 구조 개요
- docs/
- L-OMM/
- mobile_manipulator/
- tracer_mini/
- map/
- path/
- \# path/
- \# prev/
- \# reference/
- 그 외 루트 실험 스크립트 및 분석 문서

## 폴더별 설명

### docs/
프로젝트의 기준 문서 모음.
- 역할: 지침, 연구 목표, 모듈 개념 문서 관리
- 하위 구성:
  - INSTRUCTIONS 계열 문서: 응답/작업 규칙
  - Research_Topic: 연구 전체 목표와 제약
  - module 문서군: perception, decision, control, whole body 확장 설명
  - file_structure: 현재 문서

### L-OMM/
연구 메인 코드베이스와 실험 자산이 모이는 핵심 폴더.
- 역할: 인지-의사결정 파이프라인 구현, 모델 변환, 실험 스크립트 실행
- 하위 폴더:
  - assets/: 시각화 및 테스트 리소스
  - cache_dataset/: 데이터셋 캐시 및 주석 자원
  - config/: 모델 설정 리소스
  - scripts/: 파이프라인/실험 실행 스크립트 묶음
  - weights/: 모델 가중치 저장소

### mobile_manipulator/
모바일 베이스와 매니퓰레이터를 통합한 ROS2 패키지.
- 역할: 통합 URDF, 런치, 제어 설정 및 시각화
- 하위 폴더:
  - config/: 제어/초기값 설정
  - launch/: 통합 실행 진입점
  - urdf/: 베이스, 암, 카메라 통합 모델 계층
  - meshes/: 로봇 모델 리소스
  - rviz/: 시각화 설정

### tracer_mini/
모바일 베이스 드라이버 및 주변 패키지 집합.
- 역할: 베이스 통신, 제어, 센서 드라이버, SDK 제공
- 하위 폴더:
  - serial-ros2/: 시리얼 통신 라이브러리
  - sllidar_ros2/: 라이다 드라이버
  - tracer_description/: 베이스 URDF/시각화 자원
  - tracer_ros2/: 베이스 제어 및 메시지 패키지
  - ugv_sdk/: UGV 공용 SDK 계층
  - um7/: IMU 드라이버

### map/
매니퓰레이터 가용성 맵/비용맵 생성 및 성능 실험 폴더.
- 역할: 오프라인 맵 생성, 해상도/파라미터 실험, 맵 결과 보관
- 하위 폴더:
  - final_map 계열 폴더: 버전별 최종 맵 산출물
  - y_test 계열 폴더: y 축 관련 테스트 실험
  - test 계열 폴더: 실험 배치 결과

### path/
경로 계획 결과와 비교 실험 산출물 폴더.
- 역할: 경로 생성 결과 저장, 스윕 실험 결과 관리
- 하위 폴더:
  - a_star/: A* 기반 결과 묶음
  - path_test 계열 폴더: 조건별 경로 테스트 세트
  - sweep 계열 폴더: 하이퍼파라미터 스윕 결과

### # path/
대규모 경로 산출물을 별도로 축적한 보관 폴더.
- 역할: 장기간 누적된 경로 결과 아카이브
- 특징: 파일 수가 많아 직접 전수 탐색 대신 필요한 범위만 선택 조회 권장

### # prev/
이전 버전 실험 코드 및 중간 산출물 보관 폴더.
- 역할: 회귀 비교 및 과거 설정 재현 참고
- 특징: 현재 기준 구현보다 과거 스냅샷 성격이 강함

### # reference/
참고 논문 PDF 보관 폴더.
- 역할: 관련 연구 레퍼런스 저장
- 특징: 코드 실행에는 직접 관여하지 않는 지식 자원
